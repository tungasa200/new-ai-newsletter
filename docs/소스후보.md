## 4. 공통 수집 원칙

- 본문을 통째로 옮기지 않는다. 요약 몇 문장과 원문 링크만 싣는다(저작권·약관 위험을 줄인다).
- HTML 수집 대상(Anthropic News, Meta, xAI, Gemini changelog, Claude 앱 노트)의 robots.txt와 이용약관은 **아직 확인하지 않았다**. 구현 전에 확인하고, 금지된 경로는 뺀다.
- 정직한 User-Agent를 쓰고, 하루 1회만 수집하며, 소스마다 요청 1–3회로 제한한다.
- 1차 도입(A) 기준 소스는 약 20개다. 하루 수집량은 중복을 빼기 전 50–150건으로 추정한다(레거시 실행 로그가 없어 실측값은 아니다).
